# 附加文件、图片与粘贴

越精确地把上下文指给 Grok，结果越好。把内容送进提示有三种方式：

## 用 `@` 提及文件

输入 `@` 会弹出模糊文件选择器——行范围也支持：

```
@src/main.rs          附加文件
@src/main.rs:10-50    只附加指定行
@!.env                用 @! 够到隐藏文件
```

## 粘贴图片

截图可以直接粘进提示：macOS 用 `Cmd+V`，Linux 用 `Ctrl+V`，Windows 用 `Alt+V`。报错弹窗、设计稿、架构图都很好用。

## 自己跑 shell 命令

在空提示输入 `!` 可以直接跑 shell 命令——输出会落在回滚区，Grok 同样看得到。
