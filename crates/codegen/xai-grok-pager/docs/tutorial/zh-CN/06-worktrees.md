# 并行工作：工作树

想让 Grok 在一个功能上干活，同时你（或另一个 Grok 会话）在同一仓库里干别的？**Git 工作树**给每个会话一份独立检出——互不踩脚，也不用 stash。

## 在工作树里开会话

- **在哪都能按：** `Ctrl+N`（按两次确认）新建会话，然后选工作树选项。
- **欢迎页：** 在 git 仓库里按 `Ctrl+W` 打开新建工作树对话框。
- **命令行：**

  ```bash
  grok --worktree=my-feature "refactor the auth module"
  ```

  （注意用 `=`——否则提示会被当成工作树名字。）

## 好在哪

- 同一仓库同时跑两三个 Grok 会话。
- 试错被隔离开——改崩了，主检出毫发无损。
- 活干完，按普通 git 分支一样合回去就行。

**`/fork`** 把当前会话复制成一个并行会话——带上指令让它去干具体任务：`/fork try the async approach`。

同时跑好几个智能体？**智能体面板**（`/dashboard` 或 `Ctrl+\`）按状态列出所有会话——谁等输入、谁干活、谁干完了，一目了然。
