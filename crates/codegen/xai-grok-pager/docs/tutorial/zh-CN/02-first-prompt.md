# 你的第一条提示

Grok Build 是与智能体的一场对话，它可以直接在这里的终端里读代码、跑命令、改文件。

输入你想要的，按 `Enter` 发送。Grok 会把工作实时流式输出到提示上方的**回滚区**：回复、shell 命令、文件编辑都在里面。

## Grok 干活时也能继续输入

当一轮正在运行时，`Enter` 会把你的下一条消息**加入队列**而不是打断它。改变主意了？在空提示上按 `Enter` 可以停掉当前轮次，并立即发送排队的消息。

## 控制权一直在你手里

- **`Ctrl+C`**——取消正在运行的轮次（有草稿时，第一次只清空草稿）。`Esc` 不取消，只会提醒你用 `Ctrl+C`。
- **空闲时按两次 `Esc Esc`**——清空提示；提示本来就空时，则打开回退选择器。不小心清空了？`Ctrl+Z` 可以撤销。
- **`Ctrl+Q`**——退出（VS Code 系终端里是 `Ctrl+D`），按两次确认。

底部的**快捷键栏**永远显示当前最相关的按键——拿不准时就往下看。
