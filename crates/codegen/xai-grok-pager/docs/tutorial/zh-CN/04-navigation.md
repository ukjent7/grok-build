# 熟悉界面操作

屏幕分三部分：**回滚区**（会话正文）、下面的**提示**输入框，以及底部的**快捷键栏**。待办和后台任务面板会在需要时滑出来。

## 焦点

**`Tab`** 在提示和回滚区之间切换焦点。回滚区获得焦点后，可以用方向键移动选中项。

## 在会话里移动

- **`↑`/`↓`**——选中上一条/下一条记录。
- **`Shift+←`/`Shift+→`**——在轮次（你的提示）之间跳转。
- **`PageUp`/`PageDown`**——按页滚动，直接在提示里就能用，不用切换焦点。
- **`←`/`→`**——折叠/展开选中项；很长的工具输出会先收起来，需要时再看。
- **`Enter`**——在全屏查看器里打开选中项。

## 面板

- **`Ctrl+T`**——开关**待办面板**：Grok 当前任务的实时计划。
- **`Ctrl+G`**——开关**任务面板**：所有后台任务及其状态。

习惯 vim 按键？**`/vim-mode`** 可以把回滚区切到 `j`/`k`、`g`/`G` 那一套。
