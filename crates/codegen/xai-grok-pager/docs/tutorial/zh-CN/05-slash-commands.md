# 斜杠命令

在空提示输入 `/`，会弹出可搜索的命令下拉框。第一天值得认识这几个：

| 命令 | 作用 |
|---------|--------------|
| `/help` | 浏览所有命令和快捷键 |
| `/model` | 切换模型或推理强度 |
| `/resume` | 回到上次的会话继续 |
| `/new` | 开始一个新会话 |
| `/compact` | 压缩超长会话，腾出上下文 |
| `/btw` | 跟 Grok 插一句*不打断*当前任务的话 |
| `/rewind`（别名 `/undo`） | 回退到较早的轮次 |
| `/docs` | 完整操作指南，在 TUI 里或网页上看 |
| `/feedback` | 给团队发送反馈 |

其中两个值得多看一眼：

- **`/compact`** 可以带提示：`/compact keep the auth details`。随时用 `/context` 看上下文用量——窗口快满时 Grok 也会自动压缩。
- **`/rewind`**（或 **`/undo`**）回退到较早的轮次，会丢掉后面的轮次（文件改动保留原样）。

## 命令面板

按 **`Ctrl+P`**（或在回滚区按 `?`）打开命令面板——所有命令、快捷键、技能放在一个可搜索的列表里。还有完整的快捷键速查表 `Ctrl+.`（如果终端吞掉了这个组合，就用 `Ctrl+X`）。

不用死记：`/` 和 `Ctrl+P` 永远会告诉你现在能用什么。
